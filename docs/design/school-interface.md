# 課輔介面共用框架（第三階段）

## 基準與適用範圍

- 沿用教會 OS `app-design-tokens.css` 的語意色彩、Apple 系統字體及自製 SVG 路徑。此檔案為 2026-10-09 框架快照；日後同步需檢查介面差異。
- `index.html` 與 `index2.html` 共用 `school-ui.js`、`school-ui.css`、`school-icons.js`。保留兩個入口原有的業務差異，不覆蓋成同一份舊版本。
- `enrollment.html` 共用同一套 tokens、SVG、確認視窗與未儲存提醒；工作站自己的建檔、相機與閒置鎖定流程繼續由 `enrollment.mjs` 管理。
- 所有課輔頁的品牌列為 **80 CSS px**；桌面另有 60px 功能導覽，手機使用底部四個入口。課輔為現場操作工具，採共用框架的精簡表頭；不套用教會 OS 管理首頁的 164px 大型封面。
- 一般文字使用 `--app-ink`／`--app-secondary`；主要動作使用 `--app-accent` 搭配白字。成功、警示與錯誤採對應語意色；禁止以淺色圖示底色當文字顏色。
- 輸入欄位至少 16px；主要觸控按鈕至少 44px。支援縮放、可見鍵盤焦點及減少動畫。所有螢幕適配樣式限定 `@media screen`，保留列印文件排版。

## 功能目錄與權限

`SchoolUI.catalog` 是桌面導覽、手機功能收納盒與常用入口的共同來源，每項必須有 key、title、description、group、symbol、roles 及 route/href。

| 分區 | 入口 |
| --- | --- |
| 學生與到班 | 到班打卡、學生名冊、學生建檔 |
| 課堂紀錄 | 課堂點名 |
| 同工與排班 | 排班行事曆、教職同工 |
| 關懷與聯繫 | 個別輔導、家長留言 |
| 管理工具 | 報表與列印、資料匯入 |

- 同工：10 個入口；老師／工讀生：8 個入口；未登入：到班打卡與獨立建檔入口。
- 報表、匯入維持僅管理同工可用。老師及工讀生的新增、修改、刪除限制沿用原處理函式和伺服器權限。
- 公共工作站仍須專用配對及密碼；顯示入口不代表已授權。
- 學生／教職同工入口對應同一張名冊的類別篩選，不建立第二份人員資料。
- 手機「更多」可搜尋所有有權限的功能；新增功能須登錄此目錄，避免手機漏掉入口。

## 表單與互動契約

- 共享對話框：有名稱、焦點循環、Escape 取消、返回原觸發按鈕、背景 inert、捲動鎖定。浮窗內容在自己的範圍捲動。
- 破壞性操作保留確認步驟；點數理由與家長回覆使用可輸入的確認視窗；紀錄使用可捲動的文字視窗。
- 由實際儲存處理函式成功後呼叫 `schoolClearDraft`；HTTP 成功或點選送出本身不代表資料已完成儲存。
- 失敗保留輸入；儲存中阻止關閉；不自動解除既有 readonly／disabled 控制。
- 離開編輯表單、切換未儲存的點名頁或日期時，需確認放棄修改。重新載入只有確實讀取成功才清除點名草稿狀態。
- 手機排班預設清單；仍可切換可左右捲動的月曆。日期及已排班項目使用有名稱的鍵盤可達按鈕。
- 共用程式是顯示層，透過 `window.schoolInterface` 呼叫既有授權處理函式；不得把目錄或偏好當作伺服器授權依據。

## 驗收與恢復

- `node --test`：既有資料與權限回歸，以及共用目錄、入口與視覺契約測試。
- `MSCHOOL_FRONTEND_FILE=index2.html node --test tests/check-in-smoke.test.mjs tests/ui-wiring.test.mjs`：第二入口的流程與事件連接。
- 隔離瀏覽器：320／393／1440px、兩個行政入口、三種登入角色、公共建檔頁；API 使用合成資料，不以正式個資做畫面證據。
- 瀏覽器模擬不等於真實 iPhone 或 Mac Safari；實機、相機、列印與現場條碼槍另列待驗收，不能據此宣稱 99%。
- 只調整前端與設計契約，無資料庫／API 遷移。恢復方式為 revert 本次合併並重新發布 Pages；可回到第三階段前的 `eac99298718c95499014badfa5a0f1210e581601`。
