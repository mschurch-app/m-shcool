# 課輔系統共用介面

基準日期：2026-10-09。依使用者要求，整套課輔系統與教會首頁採用同一設計框架；手機以 iPhone、桌面以 Mac 為驗收基準。

## 樣式來源

- 教會網站 `mwebsite/site-design.css`：白色表面、暖灰背景、珊瑚色操作、深色文字與安靜的邊框。
- 教會網站 `docs/design/interface-framework.md`、`device-acceptance.md`：系統字體、44 CSS px 觸控、清楚對比、放大文字與減少動效。
- 本專案 `school-homepage.css`：管理用途的適配層，載於既有樣式之後，限定 `.school-app` 與螢幕媒體，保留紙本報表既有契約。

## 共用規格

| 項目 | 規格 |
| --- | --- |
| 主要文字 | `--school-ink: #302823` |
| 次要文字 | `--school-secondary: #685d57` |
| 操作強調 | `--school-accent: #ad3c2a`；白字對比優先於首頁裝飾色 |
| 表面與邊框 | 白色／`#faf8f5`／`#e9e3dd` |
| 字體 | Apple 系統字體優先，繁中使用 PingFang TC／Noto Sans TC 後備 |
| 內容寬度 | 桌面 1160 px 上限；手機依可用視窗寬度 |
| 表頭 | 桌面品牌列最少 80 px、手機 76 px；桌面功能列另計，放大字體可增高 |
| 按鈕與欄位 | 最少 44 px 高；清楚焦點與停用狀態；手機欄位 16 px |
| 卡片 | 桌面 16 px、手機 14 px 圓角；低強度陰影 |
| 狀態 | 成功／提醒／錯誤保留語意；新增、儲存等主要動作使用共用強調色 |
| 列印 | 不套用螢幕主題；保留 A4 版面、換頁與 QR Code 尺寸 |

一般文字目標至少 4.5:1、大字 3:1。局部文字／圖示與實機對比仍須逐頁驗收，不能以 CSS 或模擬測試宣稱達到 99%。

## 變更邊界及回復

本版只加入 CSS、呈現用 class 及允許縮放的 viewport。兩個 HTML 入口沿用相同主題；登入、API、資料表、權限規則、簽到、點名及列印程式維持既有版本。

如需回復，撤回本版 commit，即恢復原本兩個入口及樣式引用；無資料庫回復需求。

## 驗收

已執行既有 41 項 Node 測試，加入主題規格測試後共 44 項通過；另以隔離資料檢查 393／320／1440 px 視窗、8 個功能頁、3 種主要表單、減少動效與列印表頭。測試不接觸正式資料。

iPhone 實機相機、Safari、LINE 內建瀏覽器、文字放大、輔助使用及完整工作流程仍須獨立驗收。前端按鈕可見不代表後端授權成立，權限修正應另案實作及回歸。
